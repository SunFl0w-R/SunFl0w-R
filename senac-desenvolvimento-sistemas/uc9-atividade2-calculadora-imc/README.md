## 📌 Contexto

Atividade avaliativa entregue no curso técnico de Desenvolvimento de Sistemas (Senac), simulando uma encomenda real: um sindicato de nutricionistas precisava de uma ferramenta desktop rápida para cálculos comuns da rotina clínica, sem depender de planilhas manuais.

## ⚙️ O que a aplicação faz

Uma tela inicial navega entre três calculadoras:

| Módulo | Entrada | Saída |
|---|---|---|
| **IMC** | Peso e altura | Índice de Massa Corporal + classificação (Magreza → Obesidade grave) |
| **Gasto Calórico** | Sexo, dados corporais, nível de atividade física | Gasto calórico basal e total |
| **Recomendações** | Total calórico | Distribuição em gramas de carboidratos, proteínas e gorduras |

Cada tela valida o preenchimento e trata entradas inválidas sem travar o programa.

## 🎓 O que essa entrega representa na minha jornada

Esse projeto fecha o ciclo prático da UC9, aplicando em conjunto o que venho construindo desde as primeiras unidades do curso:

```

banco de dados (UC3/UC4)     →  raciocínio de modelagem de dados
Java & POO (UC6)             →  estrutura das classes da aplicação
boas práticas (UC7)          →  organização e manutenibilidade do código
UX/UI (UC8)                  →  clareza da navegação entre telas
interfaces desktop (UC9)     →  construção da tela em Swing/NetBeans
```
