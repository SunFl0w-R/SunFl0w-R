## 🧭 Sobre este repositório

Aqui reúno os exercícios e projetos avaliativos desenvolvidos ao longo do curso técnico em Desenvolvimento de Sistemas (Senac), aplicando na prática a lógica analítica que já uso no dia a dia profissional, agora estruturada em código.

## 🧠 Trilha de conhecimento

```
UC1 → UC2 → UC3 → UC4 → UC6 → UC7 → UC8 → UC9 ⏳
base   lógica  BD I    BD II   Java   boas    UX/UI  interfaces
                                       práticas         desktop
```

| UC | Competências |
|---|---|
| **UC1** | Pensamento computacional, metodologias e projeto de software |
| **UC2** | Lógica de programação, algoritmos, vetores/matrizes, sub-rotinas |
| **UC3** | Modelagem ER, SQL (DDL/DML), consultas com múltiplas tabelas |
| **UC4** | Segurança de dados, triggers, procedures, transações, normalização |
| **UC6** | Java, POO, herança e polimorfismo |
| **UC7** | Ágil, UML, SOLID, padrões de projeto, refatoração |
| **UC8** | UX/UI, usabilidade e acessibilidade |
| **UC9** ⏳ | Swing/NetBeans, validação de formulário, manipulação de arquivos |
